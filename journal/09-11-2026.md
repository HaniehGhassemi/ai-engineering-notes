# 🤖 AI Agents

### 1. What is an AI Agent?
A system that uses an AI model to interact with its environment and achieve a user-defined goal through reasoning, planning, and taking actions.

### 2. The Spectrum of Agency
Levels of autonomy in AI systems:

`Simple Processor → Router → Tool Caller → Multi-step Agent → Multi-agent System`

### 3. What AI Models Are Used in Agents?
- **LLMs (Large Language Models)** are the most common models used as the core reasoning engine of AI agents.
- Other models, such as VLMs (Vision Language Models), can also be used.

### 4. Tools vs. Actions
- **Tools:** Capabilities provided to an agent to interact with its environment.
- **Actions:** Operations an agent performs using available tools. One action can involve multiple tools.
